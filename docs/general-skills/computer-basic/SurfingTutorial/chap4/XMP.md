# 额外学习资源与其他

为了更好地理解硬件和软件的基本概念，推荐关注和学习以下内容：

## 硬件与 DIY
在买电脑和日常使用中，多了解硬件知识能帮你避开很多坑，并且能解决一些基础故障。推荐在 Bilibili 等平台上关注以下类型的内容：
- **装机教程**：了解主板、CPU、内存、硬盘和显卡的组装与搭配。
- **性能天梯图**：如 CPU 和显卡天梯图，了解硬件性能相对位置。
- **内存 XMP**（Extreme Memory Profile）：在主板 BIOS 中开启 XMP 或 EXPO（AMD），可以让内存运行在标称的高频率下，而不是默认的低频率。这对提升游戏和整机性能非常关键。

## 系统维护
- **PE系统（Preinstallation Environment）**：学习制作一个装有微PE（WePE）或 FirPE 的 U盘启动盘。它是你的系统急救箱，能让你在 Windows 崩溃无法开机时，进入微型系统备份硬盘里的重要文件，甚至无损重装系统。

## 开源与技术社区
- **GitHub**：全球最大的程序员交友与代码托管网站。有很多有用的开源软件和工具可以在上面找到并免费使用。
- **V2EX、知乎、吾爱破解等**：可以遇到各类技术讨论或寻找软件资源。

掌握了搜索能力、基础的系统操作与维护原则之后，你的数字生存技能就已经超越了绝大多数同学。勇敢去折腾吧，大部分系统级问题通过重装系统都可以解决，重要的是养成**数据分离与备份**的好习惯！
