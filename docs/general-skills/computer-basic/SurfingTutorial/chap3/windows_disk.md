# 硬盘分区与文件系统：数据的“公寓大楼”

作为计算机专业的学生，你需要理解硬盘是如何从一块物理金属/闪存芯片变成你电脑里一个个 C 盘、D 盘的。

## 1. 物理硬盘 vs 逻辑分区
- **物理硬盘**：你拿在手里的实体（SSD 或 HDD）。
- **逻辑分区 (Partition)**：在系统里看到的 C 盘、D 盘。
- **神技**：如果你的电脑只有一个 C 盘，建议通过“磁盘管理”分出一个 D 盘专门放数据。这样重装系统时，D 盘的数据不会丢失。

## 2. 关键术语解析

### 分区表格式：MBR vs GPT
- **MBR (老旧)**：支持最大 2TB 硬盘，最多 4 个主分区。
- **GPT (现代)**：支持超大硬盘，几乎无限分区，配合 UEFI 启动速度快且更安全。2020 年后的电脑请务必使用 GPT。

### 文件系统：NTFS vs exFAT
- **NTFS**：Windows 的标配。支持权限控制、压缩、断电恢复。
- **exFAT**：U 盘和移动硬盘的首选。在 Windows 和 Mac 之间通用性最强。

## 3. 分区建议 (最佳实践)
- **C 盘 (系统盘)**：建议 150GB - 256GB 以上。随着软件更新，C 盘会膨胀。
- **D 盘 (软件/项目)**：安装 VS Code、Python、游戏等大的软件。
- **E 盘 (备份/资料)**：存放照片、视频和安装包镜像。

## 4. 推荐工具：DiskGenius
如果系统自带的“磁盘管理”功能不够用，请使用国产神级软件 **DiskGenius**。它可以帮你：
- 找回误删的分区。
- 无损转换分区表格式 (MBR <-> GPT)。
- 坏道检测。

---
> **警告**：对分区进行“格式化”或“删除”操作会永久清除数据。在操作前，请务必确认你的数据已有备份！
