# 认识 Windows 磁盘与文件系统

在日常使用中，我们经常说“C盘满了”、“把游戏下到D盘”。那么，Windows 中的磁盘到底是怎样运作的？

## 1. 物理硬盘 vs 逻辑分区

当你买了一台电脑，里面通常装了一块有着标称容量的物理硬盘（例如一块 1TB 的 SSD）。
为了方便管理文件，我们会在这一块物理硬盘上划出不同的“逻辑区域”，并给它们分配盘符，比如 \C:\ 和 \D:\。这就是**逻辑分区（Partition）**。

- 这个过程就像是：你买了一套 100 平米的毛坯房（物理硬盘），然后用墙壁把它隔成了卧室（C盘）、客厅（D盘）和书房（E盘）。

## 2. C盘 (系统盘) 的特殊地位

在 Windows 中，C盘具有至高无上的特殊地位，因为**操作系统（Windows 本身）就安装在这里**。

- **C盘空间不足的后果**：Windows 需要一定的剩余空间来存放虚拟内存（临时交换数据用）、更新下载缓存和休眠文件。如果C盘飘红（通常剩余空间小于 10GB），你的电脑会明显变得非常卡顿，甚至无法开机。
- **软件安装原则**：为了保持系统的干净和快速响应，除了浏览器、微信这类每天高频使用的核心软件可以默认装在C盘，像几百个 GB 的大型游戏、Adobe 全家桶、各种大型开发环境，**强烈建议在安装时手动修改路径到 D 盘！**。

## 3. 文件系统 (File System)

文件系统是你修好墙壁（搞好分区）后，用来管理存放物品（数据）的底层整理规则。目前主流的有以下几种：

### NTFS（New Technology File System）
- **适用场景**：电脑的本地硬盘（C盘、D盘默认全都是 NTFS）。
- **特点**：支持单个文件最大 16EB（无限大），支持复杂的权限管理和文件压缩，安全性高，支持日志记录（断电不易丢数据）。

### FAT32
- **适用场景**：一些小容量的旧式 U 盘，或者用来刷主板 BIOS 的特定格式 U 盘。
- **特点**：兼容性极强，几乎所有的老电视、车载音响都能认出它。但它有个致命缺点：**不支持存放大于 4GB 的单文件！** 如果你用 FAT32 的 U盘拷贝一个 5GB 的电影，它会提示“目标驱动器已满”（即使你的 U 盘还有 30GB 空闲）。

### exFAT
- **适用场景**：目前**大容量 U 盘和移动硬盘的最佳选择**。
- **特点**：微软专门为闪存设备推出的格式。它既能存大于 4GB 的大文件，又能在 Windows 和 macOS 上完美实现即插即用和顺畅读写。如果你买了一个新 U 盘，建议第一时间右键格式化为 exFAT。
