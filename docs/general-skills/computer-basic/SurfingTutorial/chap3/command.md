# 命令行基础

在日常使用电脑时，我们可以通过图形界面（GUI）点击鼠标来完成各种操作。除了图形界面，我们还可以通过**命令行（CLI，Command Line Interface）** 通过输入纯文本指令来与操作系统交互。

## 什么是命令行？

命令行是一种文本界面，允许用户通过输入命令来执行程序、管理文件和系统配置。在 Windows 中，常见的命令行工具有：

1. **命令提示符 (cmd)**：Windows 最经典的命令行工具。
2. **PowerShell**：比 cmd 更强大，支持面向对象的脚本语言，通常带有蓝色的背景。

## 如何打开命令行？

- **使用运行窗口**：按下 \Win + R\ 键，输入 \cmd\ 或 \powershell\，然后按下回车。
- **通过开始菜单**：点击开始菜单，输入 \cmd\ 或 \powershell\ 进行搜索并打开。
- **在文件资源管理器中打开**：在文件夹的地址栏中输入 \cmd\，回车即可在当前路径下打开命令提示符。

## 常用基础命令

以下是一些在 Windows 命令行中最常用的基本指令：

### 1. 切换目录 (cd)

在命令行中，你始终处于某个“当前目录”下。

\\\cmd
:: 进入 D 盘
D:

:: 进入当前目录下的 Test 文件夹
cd Test

:: 返回上一级目录
cd ..
\\\

### 2. 查看目录内容 (dir)

列出当前文件夹下的所有文件和子文件夹。

\\\cmd
dir
\\\

### 3. 创建文件夹 (mkdir / md)

\\\cmd
mkdir NewFolder
\\\

### 4. 复制与移动文件 (copy / move)

\\\cmd
:: 复制文件
copy source.txt destination.txt

:: 移动（或重命名）文件
move oldname.txt newname.txt
\\\

### 5. 删除文件与文件夹 (del / rmdir)

\\\cmd
:: 删除文件
del temp.txt

:: 删除空文件夹
rmdir EmptyFolder
\\\

## 为什么要学习命令行？

虽然图形界面直观且易用，但命令行有其独特的优势：
- **效率**：可以通过简短的命令快速完成复杂的批量操作。
- **自动化**：可以通过编写批处理文件（.bat）或脚本来自动执行重复性任务。
- **开发必备**：学习编程（如 Python、C++ 等）、使用版本控制工具（如 Git）都离不开命令行环境。
