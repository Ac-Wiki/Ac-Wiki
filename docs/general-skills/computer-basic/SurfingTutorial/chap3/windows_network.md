# Windows 网络设置与排障

不论是在连接校园网、配置路由器，还是面对“为什么我的电脑连上了 WiFi 却上不了网”的灵魂拷问，掌握基本的 Windows 网络知识和排障指令都是非常有必要的。

## 1. 认识网络适配器 (网卡)

网络适配器就是俗称的“网卡”，它是你的电脑连接外界的门户。主要分为两类：
- **以太网 (Ethernet)**：有线网卡，通过网线连接，速度最稳、延迟最低，打游戏首选。
- **WLAN (Wi-Fi)**：无线网卡，连接无线热点。

**如何查看和管理网卡？**
1. 按下快捷键 \Win + R\ 打开运行窗口。
2. 输入 \
cpa.cpl\ 后回车。
3. 出现的“网络连接”窗口中，你可以直观地看到所有网卡的状态。
   - 如果某个网卡显示灰色 已禁用，你可以右键点击它选择“启用”。
   - 当遇到网络连接卡死、连上没网等疑难杂症时，有时 **右键 -> 禁用**，等几秒后再 **右键 -> 启用** ，这一套“软重启网卡”的组合拳就能奇迹般地解决问题。

## 2. 检查网络参数 (ipconfig)

在命令行（cmd 或 PowerShell）中输入 \ipconfig\ 即可快速了解当前网络状态：

\\\powershell
ipconfig
\\\
主要关注以下三个参数：
- **IPv4 地址 (IP Address)**：你在这片局域网内的“门牌号”，常见的如 \192.168.1.5\ 或者是校园网分的 \10.x.x.x\。
- **子网掩码 (Subnet Mask)**：用来划分网络区域，常见的是 \255.255.255.0\。
- **默认网关 (Default Gateway)**：内网通向互联网的总出口，通常就是你的**路由器的管理 IP 地址**（例如 \192.168.1.1\）。在浏览器里输入这个地址，就能进入路由器的后台管理页面。

如果你的 IP 地址是 \169.254.x.x\，说明你的电脑没有正常从路由器获取到 IP，一般是网线没插好或者路由器的 DHCP 服务挂了。

*(输入 ipconfig /all 可以查看更详细的信息，包括网卡的 MAC 地址/物理地址。)*

## 3. 测试连通性 (ping)

\ping\ 是史上最伟大的网络测速与故障排查工具。它会向目标发送一小个数据包，然后计算它传过去再传回来需要的时间（延迟）。

**用法：** 在终端中输入 \ping <目标网址或IP>\。
\\\powershell
ping baidu.com
\\\
如果返回 \时间=25ms\，说明网络通畅且速度不错。如果返回 \请求超时 (Request timed out)\，则说明网络不通或者对方拒绝了你的访问。

**排障三连 \ping\：**
1. \ping 127.0.0.1\：这是本地回环地址，通了说明你电脑的网卡驱动没毛病。
2. \ping 你的网关IP\ (如 \192.168.1.1\)：通了说明你电脑到路由器的连接没问题（内网通畅）。
3. \ping 223.5.5.5\ 或 \ping baidu.com\：测试外网连通性。如果 ping 数字能通，但是 ping 域名不通，说明是 DNS 坏了。

## 4. DNS: 域名解析服务

**什么是 DNS？**
电脑不认识 \www.bilibili.com\，它只认识 \119.29.29.29\ 这种纯数字 IP。**DNS（Domain Name System） 就是互联网上的“电话号码簿”**，它帮你把字母域名翻译成相应的数字 IP。

**网络正常但网页打不开？可能是 DNS 挂了！**
有时候你的微信能正常发消息聊天（因为微信基于 IP 直接连接），但打开浏览器却怎么也进不去任何网页。这多半是因为运营商分配的默认 DNS 节点出故障崩溃了。

此时，你可以手动修改使用公共、可靠的 DNS：
- **阿里 DNS**：\223.5.5.5\ 和 \223.6.6.6\
- **腾讯 DNSPod**：\119.29.29.29\
- **114 DNS**：\114.114.114.114\
- **Google 公共 DNS**：\8.8.8.8\（通常需要魔法才能连稳）

**如何在 Windows 中修改？**
在 \
cpa.cpl\（网络连接）面板中，右键你正在使用的网卡 -> **属性** -> 找到 **“Internet 协议版本 4 (TCP/IPv4)”** 双击 -> 选择**“使用下面的 DNS 服务器地址”**，然后填入上面的公共 DNS IP 即可。

## 5. 解除系统代理 (VPN 后遗症)

有很多同学在使用完某些“科学上网”代理软件（VPN）后，软件非正常关闭（比如直接结束进程或电脑意外断电），导致代理软件没有来得及清理它在系统中强制留下的代理设置。

这会导致你开机后**什么网页都打不开，所有网络服务全部瘫痪**，浏览器提示类似 \ERR_PROXY_CONNECTION_FAILED\。

**解决办法：**
1. 按 \Win + S\ 搜索 **“代理服务器设置”** 并打开。   *(🚀 快链：点击 [打开“代理服务器”设置](ms-settings:network-proxy) 直接跳转)*2. 在“手动设置代理”这一栏中，将**“使用代理服务器”的开关关闭**。
3. 确保“自动检测设置”处于开启状态。正常情况下，网络将立即恢复。

## 6. 网络急救神油指令！

如果以上方法全部失败，网络还是处于某种玄学的连接异常状态，你可以祭出微软官方的“网络重置绝杀指令”。它会清空几乎所有的网络状态缓存并重置底层通信目录。

在**以管理员身份运行的命令提示符（cmd）或 PowerShell** 中，逐行输入并回车：

\\\powershell
:: 刷新 DNS 客户端解析缓存
ipconfig /flushdns

:: 重置网络接口卡设置
netsh int ip reset

:: 重置 TCP/IP 协议栈（修复 Winsock 目录）
netsh winsock reset
\\\
执行完毕后，重启电脑。大约 95% 以上令人迷惑的 Windows 本地网络软件故障，都会在此次重启后烟消云散。
