# Windows 网络设置

对于计算机专业的学生，掌握基本的网络设置和排障方法是必修课。

## 1. 检查网络连接状态
- 快捷键：`Win + R` 输入 `ncpa.cpl`。
- 你可以直观地看到当前的以太网（网线）和 Wi-Fi 连接状态，或者在这里禁用/启用网卡。

## 2. 理解 IP 地址与网关
- 在终端输入 `ipconfig`：
    - **IPv4 地址**：你在局域网内的证件号（如 `192.168.x.x`）。
    - **默认网关**：通常是你路由器的地址（如 `192.168.1.1`）。

## 3. 修改 DNS 设置 (解决“能上微信但打不开网页”)
- 很多时候网页无法访问是因为运营商的 DNS 故障。
- **推荐 DNS**：
    - 腾讯 DNS: `119.29.29.29`
    - 阿里 DNS: `223.5.5.5`
    - Google DNS: `8.8.8.8` (需魔法)

## 4. 刷新网络缓存
当网络出现诡异问题时，可以尝试在管理员模式的终端运行：
```powershell
ipconfig /flushdns  # 刷新 DNS 缓存
netsh winsock reset  # 重置网络目录
```

## 5. 网络代理设置
- 在“设置 -> 网络和 Internet -> 代理”中，可以手动配置代理服务器，这通常是使用科学上网工具后的必要检查项。
