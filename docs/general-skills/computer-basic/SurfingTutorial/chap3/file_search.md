# 文件搜索：不再大海捞针

在计算机专业的学习中，你很快就会拥有数以万计的文件。掌握高效的搜索技能，能让你在几秒钟内找到几年前的代码片段。

## 1. 系统自带搜索 (Windows Search)
在任务栏点击“放大镜”即可。
- **优点**：能够搜索文件内容（如 Word 文档内的文字）。
- **缺点**：慢。如果文件没被“索引”，搜索过程会像蜗牛一样。
- **技巧**：在 设置 -> 搜索 -> 搜索 Windows 中开启“增强”模式。

## 2. 搜索的神：Everything (强烈推荐)
作为计算机系学生，如果没有安装 **Everything**，就像战士没有枪。
- **速度**：它是毫秒级的。只要你打出文件名，结果瞬间出现。
- **原理**：它直接读取 NTFS 磁盘的 MFT 表，不占用多余系统资源。
- **下载**：[voidtools.com](https://www.voidtools.com/)

## 3. 极客工具：grep (文本搜索)
如果你想在几千个代码文件里搜“某个函数是在哪定义的”，请使用：
- **IDE 搜索**：VS Code 中的 Ctrl + Shift + F (全局搜索)。
- **命令行工具**：grep -rn "keyword" .。这是自动化脚本和服务器运维的必备技能。

## 4. 搜索技巧：通配符 (Wildcards)
无论用什么工具，请学会这两个符号：
1. **星号 ***：代表“任意字符”。例如 *.py 代表所有 Python 文件；lab* 代表所有以 lab 开头的文件。
2. **问号 ?**：代表“单个字符”。例如 	est?.txt 能搜到 	est1.txt，但搜不到 	est10.txt。

---
> **建议**：搜索只是补救。最好的办法是养成 **合理的文件夹命名习惯**（例如 2024_Spring_DataStructure_Project1），让大部分文件在你的直觉范围内。
