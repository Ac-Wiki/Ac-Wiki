# 文件搜索：告别大海捞针

在大学四年中，你会积累无数的课件、PPT、文档、下载的代码压缩包、截图……当文件数量达到几十万甚至上百万级别时，如何在一秒钟内找到你想要的内容？

## 1. 为什么放弃 Windows 自带搜索？

平时我们习惯在文件资源管理器右上角的搜索框，或者任务栏的“放大镜”里搜索文件。但 Windows 原生的搜索有两个致命缺点：
1. **慢得出奇**：如果没有提前构建好“索引”，它会逐个文件夹扫描，硬盘转得嗡嗡响，搜索一个文件可能要几分钟。
2. **容易搜不到**：Windows 为了节省性能，默认只索引你的由于目录（桌面、文档等），藏在 D 盘深处的文件经常搜不出来。

但它也有一个优点：它可以搜索**文档内部的文字内容**（比如搜一篇包含了“秦始皇”字眼的 Word 文件）。

## 2. 搜索神器：Everything (极度推荐)

如果你问一个程序员：“Windows 上最不可或缺的第三方软件是什么？”
那排在第一名的毫无疑问是—— **Everything**！

这是由 Voidtools 推出的一款**免费、体积仅几 MB** 的绝世神器。

### 它到底有多强？
- **极速！百秒级扫描，毫秒级响应**：几乎在你敲下搜索词的瞬间，无论你的硬盘里有 500 万还是 1000 万个文件，结果会在 0.1 秒内**瞬间列出**。
- **极其轻量**：驻留在后台几乎不耗费任何 CPU 或内存资源。

### 基本使用技巧
安装后第一次打开，Everything 会花十几秒钟扫描并构建你电脑上所有硬盘的索引。之后你只需要打开它直接输入即可。

1. **多词搜索 (空格 = AND)**：
   想找下载文件夹里的微信安装包？输入 \下载 微信 exe\。匹配含有这两个词且带 exe 的所有文件。
2. **或逻辑 (| = OR)**：
   输入 \高数 .pdf | .ppt\，可以把关于高数的 PDF 和 PPT 一起搜出来。
3. **限定路径**：
   只在特定文件夹里找？输入 \D:\作业\报告 总结.doc\。
4. **排除特定内容 (! = NOT)**：
   输入 \实验报告 !草稿\（搜实验报告，但排除名字里有“草稿”的文件）。
5. **通配符 (* 和 ?)**：
   \*.jpg\ 可以列出电脑里**所有的照片**。

### 给它绑个快捷键
建议在 Everything 的“工具 - 选项 - 快捷键”中，将“显示窗口快捷键”设置为诸如 \Alt + Space (空格)\ 或其他你顺手的组合键。
这样不论你在打游戏、写代码还是看剧，按下快捷键搜索框就会跃然屏幕中央，呼之即来挥之即去，效率爆表！

*注：Everything 绝大部分原理是基于读取 NTFS 文件系统底层的 USN 日志，因此它目前仅支持极速搜索文件名（不支持搜索文件内部的文字哦）。若要搜索代码内容，建议使用 VSCode 等编辑器的全局搜索；若要搜索 Word 等文档内容，可依赖 Windows 原生搜索或安装 AnyTXT 等工具。*
