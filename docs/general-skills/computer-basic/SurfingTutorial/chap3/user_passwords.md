# 用户密码与锁屏习惯

在数字时代，个人电脑的物理安全是隐私保护的第一道防线。很多惨痛的社交性死亡或账号被盗事件，起因仅仅是离开了没有锁定屏幕的电脑。

## 1. 建立终生受益的锁屏习惯

不管你是在寝室、图书馆、还是实验室，只要你的离开座位，哪怕只是去倒杯水或上个厕所，都请养成一个肌肉记忆：

**站起身的同时，按下 \Win + L\ 键！**
*(注：L 代表 Lock，该操作不到 0.1 秒即可瞬间锁定电脑屏蔽)*

没有密码保护的电脑，对室友、路人或别有用心的人来说，就如同大敞着门的保险库。你的微信聊天记录、浏览器中保存的各个网站登录状态、甚至存储的重要文件都唾手可得。

## 2. 设置安全的屏幕解锁方式

在 Windows 10 / 11 中，你可以通过 **“设置” -> “账户” -> “登录选项”** 来配置多种安全验证方式。
*(🚀 快链：点击 [打开“登录选项”设置](ms-settings:signinoptions) 直接跳转)*

### 传统的密码 (Password)
这是所有解锁方式的基础，通常与你的本地账户密码或微软账户密码挂钩。一旦忘记麻烦极大，请确保记牢。建议设置复杂度适中的密码作为最后兜底方案。

### Windows Hello PIN 卡
Windows 推荐的一种便捷登录方式，你只需要设置 4-6 位纯数字。
很多人疑惑：**为什么短数字的 PIN 比长密码更安全？**
- **本地性**：PIN 码是通过电脑内置的安全芯片（TPM）硬件加密后存储在本地的。即便有人在网络上截获了相关信息，离开了这台特定的物理设备，该 PIN 码毫无作用。而微软账户密码是云端验证的，一旦泄露，攻击者可以从世界任何角落登录你的账号。
- **便捷性**：更适合高频次的日常解锁。

### 生物识别 (指纹与面部)
如果你购买的笔记本配备了指纹识别器（通常集成在电源键上），或支持 Windows Hello 面部识别的红外摄像头，这是最推荐的做法：掀开屏幕/按一下电源，瞬间完成解锁，无感且极其安全。

## 3. 微软账户 vs 本地账户

在首次激活 Windows 系统或平时使用时，系统常常极力推荐你登录 Microsoft 账户。

| 特性 | Microsoft (微软) 账户 | 离线本地账户 |
| :--- | :--- | :--- |
| **同步功能** | 可以跨设备同步壁纸、浏览器收藏夹和部分系统设置 | 仅限于当前电脑本机，绝不同步 |
| **应用商店** | 下载微软商店的软件更方便 | 大部分免费软件可下，个别服务受限 |
| **设备追踪** | 支持“查找我的设备”功能，遗失后有概率定位锁定 | 无 |
| **BitLocker**| 如果系统锁死了磁盘，恢复密钥会自动备份在你的微软云端账号里 | 需要你手动将恢复密钥保存到独立 U盘或打印到纸上，极易永久丢失导致数据毁灭 |
| **隐私性** | 数据与微软云绑定，用户名通常是你账户的真实拼音或邮箱前缀 | **极高**，一切数据留在本地，用户名可随意设置（推荐全英文，避免许多国产老旧软件路径报错） |

**建议：** 如果你没有多台 Windows 设备同步需求且注重隐私，并在新电脑系统激活时掌握了切断网络“跳过联网激活”的技巧，本地账户是极简体验的好选择。否则，老老实实使用微软账户，尤其是它可以**自动备份 BitLocker 恢复密钥**，这曾拯救过无数意外更新导致硬盘锁死的大学生。

## 4. 用户账户控制 (UAC)

**用户账户控制（UAC, User Account Control）** 是 Windows 系统中当软件试图进行需要管理员权限的更改时，弹出的那个“你是否允许此应用对你的设备进行更改？”的半透明黑暗确认窗口。

部分小白用户为了图省事，或者跟着网上的一些“优化教程”，去注册表里彻底关闭了 UAC。**这是极其危险的做法！**
关闭 UAC 就等于撤掉了操作系统的门卫，所有在后台偷偷运行的恶意软件、脚本木马，都能畅通无阻地直接获取最高权限，静默修改你的系统文件、植入病毒。

- **始终保留 UAC 为开启状态（默认级别即可）**。
- 如果遇到弹窗，请稍微花一秒钟看看是哪个软件在要权限。如果是一个你根本没主动打开的流氓软件，直接点击“否”。
