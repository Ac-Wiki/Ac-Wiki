# 用户和锁屏密码

保护好你的个人电脑是保护隐私的第一步。

## 1. 设置锁屏密码
- 快捷键：`Win + L` (锁定计算机)。
- 在“设置 -> 账户 -> 登录选项”中，你可以配置：
    - **密码**：最基础的保护。
    - **Windows Hello (Pin 码)**：比长密码更快捷。
    - **生物识别**：指纹或面部识别（需硬件支持）。

## 2. 自动锁屏设置
- 建议设置“屏幕超时”后自动锁定。
- 习惯：**只要离开坐位，就按下 `Win + L`**。

## 3. 本地账户 vs Microsoft 账户
- **Microsoft 账户**：支持云端同步设置、查找我的设备、BitLocker 恢复密钥备份。
- **本地账户**：更隐私，不依赖网络登录，但丢失密码后找回非常麻烦。

## 4. 管理员权限 (UAC)
- 建议使用“标准用户”进行日常操作，仅在需要安装软件时授予管理员权限。
- 不要为了麻烦而调低系统“用户账户控制 (UAC)”的级别，它是防止静默中毒的重要防线。
