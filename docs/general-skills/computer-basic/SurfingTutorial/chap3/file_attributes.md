# 文件的组成属性

理解文件的组成是操作系统的基础。每个文件不仅包含其内容，还包含一套描述其“身份”的属性。

## 1. 核心属性

| 属性 | 说明 | 示例/备注 |
| :--- | :--- | :--- |
| **文件名 (File Name)** | 文件的名称 | 
otepad |
| **文件类型 (File Type)** | 主要由扩展名表示 | .exe |
| **文件大小 (File Size)** | 文件占用的空间量 | 196 KB |
| **文件路径 (File Path)** | 文件的存储位置 | C:\Windows\notepad.exe |
| **创建时间 (Creation Time)** | 文件最初创建的时间 | 2020年1月1日 10:00:00 |
| **修改时间 (Modification Time)** | 最后一次修改“文件内容”的日期 | **最重要的排障参考指标** |

## 2. 文件属性标记 (Attributes)

在 Windows 资源管理器中右键点击文件 -> **属性**，可以快速设置：
- **只读 (Read-only)**：防止文件被修改。
- **隐藏 (Hidden)**：在默认视图中隐藏。
- **高级 -> 内容索引**：决定是否允许系统搜索文件内容。

## 3. 文件扩展名：文件的“面具”

扩展名（如 .txt, .jpg）告诉操作系统应该使用哪个应用程序来打开该文件。

### 显示扩展名
在 Windows 10/11 的资源管理器顶部，勾选 **“查看” -> “文件扩展名”**。作为计算机系学生，这是必须开启的设置，以防被类似 重要资料.pdf.exe 的程序欺骗。

### 核心真相：文件头 (Magic Number)
扩展名只是表现，真正的类型嵌入在文件开头的几个字节中。
- .exe 开头总是 MZ
- .zip 开头总是 PK
- .pdf 开头总是 %PDF-
