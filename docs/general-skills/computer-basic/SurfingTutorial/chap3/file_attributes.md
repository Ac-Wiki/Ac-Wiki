# 文件的扩展名与属性

很多人用了几年电脑，却连自己保存的是什么文件都不知道，根源就在于 Windows 默认隐藏了文件的“身份标识”——扩展名。

## 1. 什么是扩展名 (后缀名)？

文件名的完整结构是：\主文件名.扩展名\（例如 \汇报PPT.docx\）。

**扩展名**是操作系统用来识别这个文件是“什么类型”，以及“该用什么软件打开它”的唯一依据。
- \.txt\：纯文本文件，记事本打开。
- \.jpg\ / \.png\：图片文件，看图软件打开。
- \.mp4\：视频文件，播放器打开。
- \.exe\：可执行程序，系统直接运行。（**不要随便双击来路不明的.exe！多半是病毒**）

### ⚠️ 第一时间开启“显示文件扩展名”！
Windows 默认隐藏了已知文件类型的扩展名。这是微软为了“照顾小白”做出的最愚蠢的设计之一。
**后果**：骗子可以把木马病毒命名为 \美女照片.jpg.exe\。因为扩展名被隐藏，你看到的只是 \美女照片.jpg\，图标也能伪装成图片。一旦双击，你的电脑就成了“肉鸡”。

**如何开启：**
- **Win 10**：打开任意文件夹 -> 顶部 \查看\ 选项卡 -> 勾选 \文件扩展名\。
- **Win 11**：打开任意文件夹 -> 顶部 \查看\ -> \显示\ -> 勾选 \文件扩展名\。

开启后，如果你想把一个文本文件改成 HTML 网页文件，只需要右键重命名，把 \.txt\ 改成 \.html\ 即可（系统会弹窗警告可能不可用，点“是”确认）。

## 2. 快捷方式 vs 实体文件

这是一个经典的笑话：小白同学想把电脑上的游戏拷给朋友，于是把桌面上那个几十 KB 的游戏图标复制到了 U 盘里。朋友拿回去双击，除了报错什么都没发生。

- **实体文件**：真正占用硬盘空间的数据（比如 50GB 的游戏本体文件夹）。
- **快捷方式 (.lnk)**：本质上只是一个包含“路标”的超小文件，它指着硬盘里真正的文件位置。如果在桌面上把快捷方式删了，原软件毫发无损。

*辨别方法：快捷方式的图标左下角，通常会有一个**小箭头**。*

## 3. 文件及文件夹的三大属性

右键点击任何文件或文件夹，选择**“属性”**，在底部你会看到两个复选框选项。

### 隐藏 (Hidden)
- 勾选后，这个文件会在普通的文件夹视图中完全消失。
- **如何查看隐藏文件**：在刚刚开启显示扩展名的地方，勾选上**“隐藏的项目”**。此时隐藏文件会以半透明的形式显现出来。
- *系统保护文件*：有些极为关键的系统文件（如 \C:\pagefile.sys\）被加了双重隐藏保护，普通的“显示隐藏文件”也看不见。你需要去“文件夹选项”里，取消勾选“隐藏受保护的操作系统文件”才能一睹真容。（没事别开，看着眼晕也容易误删）。

### 只读 (Read-only)
- 勾选后，文件内容**只能看，不能改**。尝试保存修改时会提示没有权限或另存为。
- 在与他人共享协作文件，或者保护一些配置文件不被游戏/软件自动复原时，这是一个非常实用的小技巧。

### 系统属性 (System)
（通常只能通过命令行赋予，普通图形界面无法修改）
- 加上了系统属性的文件将被操作系统视为核心文件，难以被简单的删除指令干掉。如果遇到怎么也删不掉的顽固流氓文件，可以尝试在命令提示符中使用 \ttrib -s -r -h 文件名\ 剥夺它的保命光环。
