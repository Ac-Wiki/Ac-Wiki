# 环境变量

环境变量（Environment Variables）是操作系统用来运行环境的配置信息。它们可以看作是系统级的“全局变量”，告诉系统去哪里查找可执行程序或配置文件。

## 什么是环境变量？

最常见的环境变量是 \PATH\。当你（或某个程序）在命令行中输入一个命令（例如 \python\）时，系统首先会在当前目录下寻找有无对应的可执行文件；如果没有，系统就会去 \PATH\ 变量所包含的一系列目录路径中去寻找。

如果某个程序所在的目录没有添加到 \PATH\ 中，就会出现经典的报错信息：
>\xxx 不是内部或外部命令，也不是可运行的程序或批处理文件。\

## 如何配置环境变量？

1. 按组合键 \Win + S\ 或点击任务栏的搜索，输入**“环境变量”**。
2. 点击**“编辑系统环境变量”**。
3. 在弹出的“系统属性”窗口中，点击右下角的**“环境变量”**按钮。
4. 环境变量分为两类：
   - **用户变量**：只对当前登录的用户有效。
   - **系统变量**：对这台电脑上的所有用户有效。
5. 找到你想要修改的变量（通常是 \Path\），选中后点击**编辑**。
6. 在弹出的窗口中，点击**新建**，然后输入（或浏览）所需程序的文件夹路径（例如 \C:\Python39\）。
7. 一路点击**确定**保存设置。

## 配置生效

修改环境变量后，对于**已经打开的命令行窗口**是不生效的。你需要**重新启动一个新的命令行窗口**，系统才会读取最新的环境变量。

如果你在学习编程语言（如 Java 的 JDK，Python 的解释器，或 Node.js），正确配置环境变量通常是第一步。
