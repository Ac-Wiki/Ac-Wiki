# 磁盘管理与分区操作

在 Windows 中，你完全可以通过内置的“磁盘管理”工具，像搭积木一样自由地调整你的磁盘空间，而无需下载任何第三方分区软件。

## 1. 如何打开“磁盘管理”
最简便的方法：**右键点击**屏幕左下角的“开始菜单”（或者按 \Win + X\），在弹出的菜单中选择 **“磁盘管理”**（Disk Management）。

## 2. 认识分区视图
打开后，页面下半部分会以不同的色块展示你的物理磁盘：
- **磁盘 0、磁盘 1**：代表物理插在主板上的真实硬盘数量。
- **带盘符的区块 (C: / D:)**：正常使用的分区。
- **带有“EFI 系统分区”和“恢复分区”的隐藏块**：这是 Windows 启动所需的底层文件所在位置。**绝对不要尝试去删除或修改它们！**
- **未分配空间（黑色色块）**：这是一片还没有建房子的“荒地”，无法用来存数据。

## 3. 实操：如何把 C盘 拆一部分给新建的 D盘？

假设你刚买了一台崭新的轻薄本，1TB 的硬盘所有空间全都划给了出厂的 C盘。为了数据安全，你想要一个 D盘 专门存放个人文件。

**第一步：压缩卷（从 C盘 切出空间）**
1. 在磁盘管理中，找到 C盘 色块，**右键 -> 压缩卷**。
2. 系统会计算一会儿，然后问你“输入压缩空间量”。注意这里的单位是 MB。如果你想切出 500GB 给未来的 D盘，就在这里输入 \512000\ (1GB = 1024MB)。
3. 点击“压缩”。完成后，C盘 的右侧会多出一个黑色的“未分配”色块。

**第二步：新建卷（把未分配空间变成 D盘）**
1. 右键点击那个黑色的“未分配”色块，选择 **“新建简单卷”**。
2. 一路点击“下一步”，给它分配一个盘符（比如 D），并在格式化步骤中确保文件系统是 **NTFS**。
3. 点击完成。恭喜你，你的 D盘 已经诞生了！

## 4. 实操：如何把多余的盘合并？

如果你觉得分区太多很乱，想要把 E盘 的空间合并到 D盘 里去：

**⚠️ 警告：合并分区意味着必须被吃掉的那个分区！以下操作将会完全清空 E盘 的所有数据！请提前把 E盘 数据备份到别处。**

1. 右键点击 E盘 -> **删除卷**。删除后，E盘 会变成一块黑色的“未分配”空间。
2. *重要前提*：这块黑色的未分配空间，必须紧紧挨在 D盘 的**右侧**，且中间没有其他色块阻挡！
3. 右键点击 D盘 -> **扩展卷** -> 一路点击下一步把空闲空间吃掉。合并完成。

## 5. 什么是 BitLocker？
在磁盘管理或文件资源管理器中，你有时会看到磁盘图标上有一把**小锁**，这说明它开启了 BitLocker。
这是 Windows 专业版/教育版（现在部分家庭版也支持设备加密）提供的一种底层的全盘加密技术。它极其安全，即使小偷把你的硬盘拔下来插到别的电脑上，没有密码也绝对读不出一张图片。
- **重点**：如果在系统更新、重装或更换主板后触发了安全机制，电脑开机会要求输入一段 48 位的恢复密钥。请务必在你的微软云端账号里，或者某个安全的 U 盘里保存好这把至关重要的密钥！
