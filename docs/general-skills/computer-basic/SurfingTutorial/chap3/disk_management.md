# 磁盘管理与软件卸载：保持系统如新

随着软件和数据的增多，你的电脑会慢慢变“胖”。如果不通过科学的管理，这种膨胀会导致系统卡顿。

## 1. 软件安装的礼仪
- **拒绝一键安装 (Quick Install)**：它会把软件塞进你的 C 盘，并可能附赠三个你不想要的插件。
- **自定义路径 (Customize)**：养成将软件安装到 D:\Softwares\ 的好习惯，保持 C 盘作为纯净的系统区。

## 2. 磁盘分析工具
当你发现 C 盘红了，却不知道是什么占了空间，请使用：
- **SpaceSniffer**：以方块块图形式展现磁盘占用情况，哪块大就是哪个文件大。
- **TreeSize Free**：以目录树形式查看文件夹大小，非常适合找寻隐藏的日志文件或缓存。

## 3. 科学卸载软件
- **错误方式**：在文件夹里直接点 Delete 删除目录。这会留下大量无用的注册表项。
- **推荐工具：Geek Uninstaller**。它在调用软件自带的卸载程序后，会全自动扫描并一键清除残留，让你的电脑没有任何冗余。

## 4. 清理系统垃圾
- **磁盘清理 (Disk Cleanup)**：Windows 自带，安全清理旧补丁文件。
- **存储感知 (Storage Sense)**：在 Windows 设置中开启，它会自动清理回收站和下载文件夹。

---
> **切记**：不要随意下载所谓的“一键优化”或“强力清理”工具，它们往往会带来比垃圾文件更多的广告。
