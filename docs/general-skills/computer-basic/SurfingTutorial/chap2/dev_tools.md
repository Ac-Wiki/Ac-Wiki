# 开发者工具的一些简单操作

开发者工具（Developer Tools，简称 DevTools）是浏览器内置的一套强大的工具，虽然它是为前端开发者设计的，但普通用户掌握一些简单操作也能解决很多问题。

## 如何打开
- 快捷键：`F12` 或 `Ctrl + Shift + I`（Mac 为 `Cmd + Opt + I`）。
- 右键点击页面任何元素 -> 选择 **“检查” (Inspect)**。

## 常用功能

### 1. 元素检查 (Elements)
- **作用**：查看网页的 HTML 结构。
- **神技**：如果网页上有某个烦人的弹窗或遮罩挡住了内容，你可以点击左上角的“选择元素”图标，选中该遮罩，然后按 `Delete` 键临时删除它。

### 2. 控制台 (Console)
- **作用**：查看网页报错信息，或者运行 JavaScript 代码。
- **场景**：有些网页限制了文字复制，你可以尝试在 Console 中输入 `document.body.innerText` 来获取纯文本内容。

### 3. 网络面板 (Network)
- **作用**：查看网页加载了哪些资源（图片、脚本、视频）。
- **神技**：当你想下载网页上的某张背景图，或者查看某个接口返回的数据时，刷新页面并在 Network 面板中寻找对应的文件。

### 4. 模拟移动设备
- 点击左上角的手机/平板图标，可以模拟手机访问网页的样子。有些网站在手机版模式下下载资源更方便。

---
> **注意**：永远不要在控制台（Console）中粘贴并运行你不认识的人提供的代码，这可能会导致你的账号或隐私被窃取。
