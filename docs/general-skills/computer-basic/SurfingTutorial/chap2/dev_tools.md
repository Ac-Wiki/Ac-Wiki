# 开发者工具的一点简单操作

浏览器开发者工具（Developer Tools，简称 DevTools）是现代浏览器内置的一套强大的网页调试工具。虽然它主要是为前端开发者设计的，但普通用户如果掌握了一些简单的操作，也能极大提升上网体验，甚至解决很多“网页限制”问题。

## 如何打开开发者工具？

在绝大多数主流浏览器（如 Edge、Chrome、Firefox）中，打开方式都是通用的：
- **快捷键**：按下键盘上的 \F12\ 键。
- **快捷键组合**：\Ctrl + Shift + I\（Mac 上为 \Cmd + Opt + I\）。
- **右键菜单**：在网页任何空白处或特定元素上毫无毫无右键，选择 **“检查” (Inspect)**。

打开后，你会看到一个包含多个选项卡的面板。最常用的主要是 **Elements（元素）**、**Console（控制台）**、**Network（网络）** 和 **Application（应用）**。

---

## 1. 元素面板 (Elements)：破解网页遮罩与弹窗

**Elements 面板**显示了当前网页的 HTML 结构。你可以直接在这里修改网页内容，甚至删除碍眼的元素。

### 神技：删除强制登录弹窗或遮罩层
很多网站在浏览几秒钟后，会弹出一个强制登录的窗口，并在背后覆盖一层半透明的黑色遮罩，导致你无法滚动和阅读网页内容。
1. 按 \F12\ 打开开发者工具。
2. 点击 DevTools 左上角的 **“选取页面元素”** 图标（一个鼠标箭头指着方块的图标，快捷键 \Ctrl + Shift + C\）。
3. 移动鼠标到网页上那个烦人的遮罩层或弹窗上，点击它。
4. 此时在 Elements 面板中，对应这个元素的 HTML 代码会被高亮显示。
5. 按下键盘上的 \Delete\ 键（或右键选择 \Delete element\）。
6. 如果遮罩被删除了，但网页依然不能滚动，通常是因为 \<body>\ 标签被加了 \overflow: hidden;\。在 Elements 中找到 \<body>\，在右侧的 Styles（样式）面板中把 \overflow\ 的勾选去掉即可。

### 修改网页文字（装X必备）
选中网页上的某个标题或余额数字，在 Elements 中双击对应的文字，就可以将其修改为你想要的任何内容。截图发给朋友非常有效。

## 2. 控制台 (Console)：运行神奇的脚本

**Console 面板**用于输出网页的日志和报错信息，同时这也是一个 JavaScript 代码执行环境。

### 神技：解除网页文字复制限制
有些网站（如某些文库或小说网站）禁止右键菜单和文本选中复制。你可以通过 Console 运行简单的代码来解除限制。

**方法 A：开启设计模式**
在 Console 面板底部的输入框中输入以下代码并回车：
\\\javascript
document.designMode = 'on';
\\\
此时，整个网页变得像 Word 文档一样可以自由编辑，你自然也可以随意选中和复制所需的内容了！

**方法 B：提取纯文本**
或者你也可以直接获取整个网页的纯文本内容：
\\\javascript
console.log(document.body.innerText);
\\\

> ⚠️ **安全警告**：永远不要在 Console 中粘贴并运行你不理解的代码，尤其是别人告诉你“粘贴这段代码就可以免费充值/领取福利”时。这是一种极其典型的 **XSS（跨站脚本）攻击** 手法，可能会导致你的账号被盗！

## 3. 网络面板 (Network)：抓取隐藏的图片和音视频

**Network 面板**可以记录网页加载的所有资源（图片、脚本、音视频、接口数据）。

### 神技：下载无法右键保存的背景图
部分网站将图片设置为 CSS 背景，或者屏蔽了右键“图片另存为”。
1. 按 \F12\ 打开开发者工具，切换到 **Network** 面板。
2. 按 \F5\ 刷新网页。（因为工具打开前的请求不会被回溯记录，必须刷新）。
3. 在工具栏的筛选器（Filter）旁边，点击 **Img**（仅显示图片资源）。
4. 在列表中一个个点击请求，右侧会预览图片。找到你想要的那张，右键 \Open in new tab\（在新标签页打开），然后就可以直接保存了。

### 抓取网页视频/音频
同理，筛选器选择 **Media**，当你播放网页视频或音频时，列表中就会出现媒体文件的真实下载链接。

## 4. 模拟移动设备 (Device Toggle)

在 DevTools 的左上角，紧挨着“选取元素”图标的，是一个 **手机/平板图标**（Toggle device toolbar，快捷键 \Ctrl + Shift + M\）。

点击它后，浏览器会模拟手机屏幕的尺寸和**用户代理 (User-Agent)** 重新加载网页。
- **使用场景**：有一些网站的 PC 端非常臃肿，甚至强制要求扫码下载 App 才能阅读全文。而它们的手机端网页往往十分清爽且没有这些限制。切换到移动端视图不仅能拯救被强暴的视觉，偶尔还能方便地保存资源。

---

## 5. 应用面板 (Application)：清理缓存与破解限制

在 **Application**（应用）面板中，包含了 Local Storage、Session Storage 和 Cookies 等本地存储信息。

### 神技：突破“免费试读次数”限制
一些新闻网站或工具网站，在没有登录的情况下，会依据保存在你电脑上的 Cookie 来计算你“今天已经免费阅读了X篇文章”。
1. 打开 **Application** 面板。
2. 在左侧菜单找到 **Storage** -> **Cookies**，点击展开并选中当前网站域名。
3. 点击顶部工具栏的 **圆圈带斜杠图标 (Clear All)** 或按下 \Delete\ 键清空这些记录。
4. 刷新网页，网站就会把你当成一个全新的访客，试读次数被重置。
