# 设计课题的一些思路

本篇文字提供一些设计思路，但是不能直照着设计课题。
适用人群：

1. 需要自己找课题设计实验的硕士；
2. 想参加比赛，但是苦于科研课题申报的本科生；
3. 对科研不太了解，但是想更全面地了解科研的人群；
4. 刚入学想进实验室的本科生。

<!-- more -->

简单地描述一下，自己在课题方面的经历：

1. 2020年秋，刚入大学的那一会，好像是因为学院在举办什么创新杯，那个时候充满好奇，什么都想去体验一下，于是我就去找了大三的学长，问我们想参加这个比赛，能带我们体验一下吗？学长是挺好的学长，但是他当时忙于另外一个比赛，于是给我们详细讲述了，要是想要参加比赛，可以去找一些系里面的老师，并且详细描述了一些系里面的老师。随后，改天，我和另外一个同学一起去我们系老师的办公室，问了几个老师，因为我们对这个比赛也不太了解，也不清楚具体情况，只是抱着想体验的心态去试试看。只记得三位老师给了的一些答复了，一位是系主任，她是比较负责并且对学生友好的老师，她当时问了我们，这个比赛是要一个做完的课题，还是一个课题从零开始做，但是我们不清楚，于是她替我们去问了学院里面懂得多的辅导员，过了些天，告诉我，这个比赛是需要差不多做完的课题去参赛的，我们的条件不符合；一位是班导师，班导师那段时间刚来学校，可能很多条件都欠佳，给我说，我这边做的是基础研究，不太适合这类比赛；另外一位是班导师的师弟，也是一起刚来学校的老师，具体话语忘记了，只记得好像是说他这边暂时没本科生能做的课题。其实还有一位老师的，但是那位老师并不是我去沟通的，他对一位同学说，你们来找我需要预约什么的，当时刚入大学，大家确实不明白这些基本礼节。只知道老师在办公室，应该是可以去问的。结果就是苦于没得课题，也不知道什么是科研，就回归大学的课表生活了。现在觉得，反正是为了体验什么是科研，没得比赛也能去实验室跟着学一点东西吧，但是当时没想通，还辜负了当时相信我的同学们的期望。
2. 2021年夏天，那段时间因为系里面的导师制度，我们已经选了她当我们的指导老师。她问我们想参加这届大学生创新创业大赛吗？她现在有一个想法，然后想让我们去做。给我们讲述了一个研究方法路径，然后给了一些这个研究方法的相关学者及论文，让我们用这个研究方法去构建一个课题。于是我们通过各种途径去确定论文，比如图书馆看书，互联网看那些学者的相关文献。说实话，那段时间都不知道什么是PubMed、对 SCI 也不了解、查论文还是这位老师手把手演示的，我觉得这位老师算是我的第一个启蒙老师了。有了研究方法，就在确认研究内容，但是这个内容确定也挺玄乎的，没有经过系统性比对。而且因为中医药的一些翻译问题，可能和国外论文的一些检索词对不完全。最后的结果是，前期队长发力，中期指导老师发力，后期另外一个同学发力，带我这个躺平的人在23年秋完成了课题。中途因为参加另外一个专业比赛，延期了一年。
3. 2025年-2026年，硕士期间。硕士期间倒是没什么自己去设计课题的苦恼，导师给了我们一些初始的课题名称，然后就对着课题完善课题。并没有像一些学生，需要自己去找课题，然后再和老师讨论，但是自己在做课题的期间还是觉得自己逐步了解到一些设计课题的方法了。

描述完自己的一些和课题有关的经历，下面就来讲述自己现在的一些设计课题的思路。

## 1. 设计课题的一些误区
## 1.1 不必完美

课题初期不必完美，但是需要仔细打磨。
正如群主所言类似：

>你不能因为觉得自己的方案不够好，就不给人看，抱着这样的心态越是帮不到别人的，只要是自己真情实感的表达就已经足够了，如果别人觉得“不好”，那他们会帮助完善，如果他们不考虑帮忙，那他们实际上也不是目标对象，不必理会。

一个课题的设计初期，大概率会和最后阶段存在差异，有些时候做着做着，课题朝着预设方向逐渐完善了，有些时候做着做着，发现课题的立意有点歪，目前的科研条件大概率做不出来。这都是正常现象，所以课题初期完全可以是不完美的，是粗糙的，这都没问题。所以，当你需要一个课题的时候，你只需要满足一些基本需求，如你需要解决什么问题？这个问题背后的背景是什么，这个问题有人做吗？目前这个问题发展如何？对于新手来说，在没得依靠的时候，最好求稳妥，选择一个成熟的技术栈，看看这个方法能不能迁移到自己构思的课题上面，不要想着自己去当天才，实验科学，很难出现天才，顶多会存在你的背景比较丰富，能多学科视角看待问题。然后记得带着你的思考和调研，去找具体的线下老师，去完善自己的想法。要学会合作，多问学长，老师，多和同学交流，一般而言，同学之间没必要严防死守，带点戒心是好的，但是也没必要什么都不说，太伤害同学情分了。

## 1.2 不必太过创新

本人之前不了解什么是创新创业大赛，我一直在思考，一个好多人都在用的方法，也能算创新吗？然后我先后就这个问题，问了两个带我做课题的老师，前者说，用新的研究方法做课题，当然算得上创新，后者说，有些科研方法的创新，甚至能获得诺奖，本科生不必太过苛求创新。
所谓创新，需要你自己去思考这个词语。现在我觉得科研上面的创新，主要是三个方面吧，其一是用现阶段大家都用的阶段性新方法去分析过去的课题，或者是在其他领域用的很成熟的方法用于另外一个领域；其二，是将不同研究方面的东西给组合起来，类似于研究对象的创新，有些人研究单因素、你可以研究多因素组合，比如一个东西A对C有影响，B对A有些影响，A+B能不能影响C；其三，就是纯粹的方法学的创新，这个方法学的创新理论上还是存在层次的，可以是你开创了一个新的研究方法，也可以是你通过一些学科知识的积累，迁移，然后对现阶段的一些科研方法进行微调，具体表现在，你对某一个化学合成反应，通过查阅文献，进行了修改，或者纯化方法，提高了产率；或者，对于动物实验来说，你和别人没使用一种造模方法，对早模方法进行修改。但是我觉得对于其三来说，新手是比较难完成的，只能站在山底望一下山峰。创新之间亦有差距，先学会在已有知识体系里面完成一个合理的课题，再去思考能不能创造全新的知识或者体系。

## 1.3 考虑实际情况

科研不是纯想想就出来的，是需要时间、需要劳动力、需要经济等等成本的。有些课题过于宏大，可能要前后几代研究生才能出成果，有些实验可能消耗的经费数以百万计，有些实验可能需要的实验条件有门槛，很多地方做不了。虽然是说，做课题也可以根据实际情况优化实验条件，选择更具性价比的试剂、耗材，但是，还是得结合实际情况进行考虑。别一上来就来一个超级宏大的课题，可以选择一个宏大的方向做深入，但是不要把课题设计得太过宏大。设计课题之后，尽可能结合现阶段所拥有的资源，问问自己能不能把课题做出来，做出来的一小部分能不能回答这个课题有没有实际意义。多思考，多交流，不要闭门造车。

# 2. 一些关于课题设计的思路

讲述了一些课题设计的误区，下面就来谈谈，目前的一些课题设计的可行思路。

## 2.1 多看文献

大家都说一个问题不清楚，就去多看“文献”。但是很多时候，这个“文献”的指代有些模糊，有些时候太狭窄了。文献可以是大家发表的学术论文、各类国标标准、专利、中英文学位论文、专业书籍、各类基金申报书等等。单就一个期刊论文，很多时候都未必能查全，不要太过于依赖一些过于集成的平台，比如PubMed、Web Of Science、知网等，有时间多去了解一下，这些论文发表的期刊平台，有些研究方面的论文会集中在几个常见的期刊。然后记得多看高质量的文献，不要看太老旧，和可信度不够高的文献。新手先多看近期的好综述（影响因子高，或者老师推荐，多看看非课程教学的工具书也是可以的，比如分子克隆手册），我还推荐新手可以多看看一些实验问答贴，在小红书、B站或者国外的一些平台，能自己开始做实验之后，再去拓阔一下广度，比如销售和试剂商出的操作手册，因为可以自己动手验证一些想法了。记得多看多学多思考，我讲述的也只是在说某些地方可能有什么，它是不是真的，还需要自己去思考和探索。看文献的第一阶段，是尽可能建立对这个领域的基本认识。

## 2.2 看相关的文献

当你决定依赖几个关键词或者技术栈来完成课题设计的时候，这个时候你只需要看相关课题，研究前人在这方面做了什么，考虑一些案例数量，做一下背景调研就可以了。文献太多，大概率也会是苦恼，文献太多很容易看不过来。尽可能提取一些关键信息，你需要的信息不一定是每个文献的核心问题，可能只是带过去的只言片语罢了。有时间的话，提前看看课题组的论文，学位论文和期刊论文。

## 2.3 拓展文献面

我觉得比较正确的课题设计，应该从原因出发，而不是从结果出发，虽然它们之间存在交叉。之前告诉我在WOS上面，要关注高被引和热点论文，看别人在研究什么。我觉得其实也可以从一些基金本子出发，看需要研究什么。基金可能是横向和公司合作的、也有纵向的是从国家及地方政府的相关单位如（国家自然基金委员会、科技部、省科技厅）拨款的。可以多看看高质量的立项申报书，这些立项申报书尽可能和自己的研究方向相关，立项申报书和一些申报指南可以从小木虫、公众号、淘宝或者官网看看相关内容，也可以找老师看看往届的申报书，积累经验。
有些时候，我觉得一些本科生比赛给的申报指南里面也会提供相关的课题设计思路，比如大学生创新创业大赛、大学生生命科学竞赛。也可以看立项的相关资料和获奖内容，看看相关项目的标题，倒推一些课题设计思路。可能有人找不到立项相关资料，这也不要紧，也可以等进课题组之后，再询问老师，师兄师姐们。多问，多看，多学。


# 3. 总结

目前关于课题设计的思路，受限于个人认知水平和时间，只能初步写一写，希望后之来者，能进一步优化相关内容。祝大家有更好的未来。
